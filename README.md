# MOBET LINK — منصة اختصار روابط (MVP)

هذه نسخة تشغيل أولية كاملة للمنصة: واجهة عامة، حسابات مستخدمين، روابط مختصرة، صفحة إعلان بينية، لوحة مستخدم، طلبات سحب، ولوحة أدمن.

## مهم قبل الإطلاق
- لا يوجد دخل مضمون من مجرد النقرات. يجب التسجيل في شبكة إعلانية تسمح صراحةً بصفحات الإعلان البينية/اختصار الروابط والحصول على موافقتها.
- مساحة الإعلان في صفحة التحويل تجريبية حاليًا. لا تضع كود إعلان عشوائيًا أو تستخدم إعلانات تحفّز النقرات المخالفة.
- ربط إيرادات الشبكة تلقائيًا يحتاج API أو تقارير موثقة من الشبكة؛ في هذه النسخة يسجل الأدمن صافي الإيراد المؤكد يدويًا، ثم يوزعه النظام بنسبة الناشرين المحددة وبحسب النقرات المسجلة. لا تعتبر كل نقرة زيارة مؤهلة للإعلان.
- نظام مكافحة الزيارات الوهمية هنا أساسي فقط، وليس كافيًا لإطلاق تجاري واسع. أضف قواعد التحقق ومراجعة الشبكة الإعلانية قبل دفع أموال حقيقية.
- لا يتم تخزين IP أو الموقع الدقيق أو بصمة الجهاز. يتم تسجيل وقت الزيارة وفئة الجهاز والمتصفح ومصدر الإحالة فقط.

## التشغيل
يتطلب Node.js 20 أو أحدث:
1. فك ضغط المشروع.
2. من مجلد المشروع شغّل `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. غيّر `ADMIN_EMAIL` و`ADMIN_PASSWORD` و`SESSION_SECRET` إلى بيانات قوية وفريدة.
5. شغّل `npm start`.
6. افتح `http://localhost:3000`.

صفحات الموقع:
- الرئيسية: `/`
- حساب المستخدم: `/dashboard.html`
- لوحة الأدمن: `/admin.html`

## الاستضافة
استخدم استضافة تدعم Node.js وتخزينًا دائمًا للملفات (Persistent Disk/Volume) لأن قاعدة SQLite والجلسات محفوظة داخل مجلد `data`. اضبط:
- `NODE_ENV=production`
- `BASE_URL=https://your-domain.example`
- `SESSION_SECRET` قيمة عشوائية طويلة (32 حرفًا على الأقل)
- `ADMIN_EMAIL` و`ADMIN_PASSWORD`

فعّل HTTPS. لا ترفع ملف `.env` إلى مستودع عام. خذ نسخًا احتياطية من مجلد `data`.

## تنبيه أمني وتشغيلي
هذه نسخة MVP للتجربة وليست تدقيقًا أمنيًا أو محاسبيًا نهائيًا. قبل استقبال مستخدمين أو تنفيذ مدفوعات فعلية، يلزم إضافة تأكيد البريد، استعادة كلمة المرور، حماية CSRF مناسبة، مراجعة إساءة الاستخدام والروابط الضارة، سياسة خصوصية وشروط استخدام، وسجل تدقيق للمدفوعات. لا تعتمد على عدد النقرات وحده لتقرير الإيراد أو الاستحقاق.
